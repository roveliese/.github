## Choose your theme

After installation, open the Command Palette (`Ctrl+Shift+P`) and run **Roveliese: Select Theme**. It presents all three variants in one picker.

- **Dark** — deep mocha surfaces for low-light work.
- **Light** — warm off-white paper, not a simple inversion.
- **Storm** — cool, precise contrast without becoming generic blue.

Run **Roveliese: Configure Theme** to open the extension settings. You can tune accent color, workbench mode, navigation contrast, typography, bracket coloring, and indent guides without reloading VS Code.

## Project

The [VS Code extension repository](https://github.com/roveliese/vscode) contains previews, the full customization reference, release downloads, and issue tracking. Roveliese also includes an optional **Roveliese Product Icons** icon theme.
